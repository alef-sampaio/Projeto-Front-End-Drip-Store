# Digital Store

Projeto final de Front-end (React + Vite + React Router).

## Como rodar
1. Copie a pasta `public/` do [repositório base](https://github.com/digitalcollegebr/projeto-digital-store) para este projeto (imagens: `home-slide-*.jpeg`, `collection-*.png`, `product-thumb-*.png`, `product-image-*.png`).
2. `npm install`
3. `npm run dev`

## Rotas
- `/` Home · `/products?filter=termo` Listagem · `/product/:id` Produto
